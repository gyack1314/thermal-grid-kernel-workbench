# 地温内核的分块执行与别名保真

此项目使用本地合成资料描述相关工程场景。`inputs/` 中的语言源文本和数据契约资料可用于本地演练，不对应真实台站、城区或控制设备。

## 交换约定

网格宿主用 `storage` 指向底图和使用 `[x,y,w,h]` 描述视图，数值和有效掩码按行存储。`stage` 内从同一时点读取，阶段成功才公开写入。示例用 `read(grid, dx, dy)` 读固定邻域偏移，越界策略为 `missing`、`clamp` 或内核声明的常量。有零面积窗口时无逐格写入，归约初始值照常可见。算术用 IEEE 754 binary64，不使用改变结果的融合乘加，归约按有效格从上到下、从左到右累积，错误按源位置和同一格序归因。按规定触发除零即报错，结果不能写入当前阶段。运行预算以字节计，数值槽 8 字节，掩码槽 1 字节；显式归约槽、缓冲像素和活跃中间值计入，宿主视图引用和源文本不计。

## 资料检查

使用 CPython 3.11.2 标准库，无需安装第三方包。资料检查入口可以列出任意资料目录的路径、文件大小与原始字节摘要，并检查 JSON 和文本编码。

```sh
python3 inspect_inputs.py inputs
python3 -m unittest discover -s tests -v
```

目前入口负责资料清点，源语言文件按原始文本保存，尚未提供语言编译及执行入口。
